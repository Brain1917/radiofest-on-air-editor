# Память задачи

Память помогает продолжать работу, но не является условием первого запуска. Используй хранилище только если среда его предоставляет.

## Поля

```yaml
context:
  station: null
  audience: null
  programme: null
  presenter: null
  presenter_wpm: null
  jurisdiction: null
status:
  current_item: null
  stage: null
  blockers: []
goal:
  result_type: null
  duration_seconds: null
  success_criteria: []
decisions: []
next_actions: []
progress: []
lessons:
  confirmed_pronunciations: []
  station_language_rules: []
```

## Правила

- Сохраняй только явно подтверждённые и повторно полезные данные.
- Не сохраняй пароли, токены, секреты, закрытые исходники и лишние персональные данные.
- Не превращай разовую правку в правило станции.
- Подтверждённое произношение хранится отдельно от базового справочника.
- При продолжении задачи сначала восстанови цель, версию, блокеры и последнее решение.
- Если постоянное хранилище недоступно, выдай переносимый YAML-блок по просьбе пользователя.
- Пользователь может попросить показать, исправить или удалить сохранённое правило.

Память не служит доказательством актуальности факта. Дату, число, должность и обязательное условие проверяй заново для каждого материала.
