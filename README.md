**Редакционный помощник радио.**
Помогает подготовить материал к редакторскому решению о выпуске: получить текст, увидеть его источники и нерешённые вопросы.
Это один устанавливаемый скилл - набор инструкций для ИИ, а не отдельная редакционная система.

**Статус v0.3.0.**
Предварительная версия (prerelease). Выполнены локальные проверки пакета и текстовая сверка правил персонализации.
Сохранённые примеры в Pi и независимый обзор относятся к предыдущей версии v0.2.0, а не к новой персонализации.
Установка, обычные запросы, неявное подключение и резервный явный запуск в реальном ChatGPT НЕ проверены.
Примеры Pi выполнены с явно загруженными инструкциями и настройками среды. Они не доказывают поведение в чистой установке.
Не все пограничные варианты испытаны. Экономия времени, надёжность в процентах и преимущество перед моделью без скилла не установлены.

**Персонализация в v0.3.0.**
В инструкции добавлены профиль клиента и его чтение при каждом запуске, включая новый чат, если среда предоставляет доступ.
Профиль задаёт аудиторию, стиль, форматы и ограничения. Текущая просьба может разово изменить оформление, не перезаписывая постоянные настройки.
Можно попросить «запомни: посты без эмодзи», «покажи мои настройки», «измени правило» или «забудь эту настройку».
Сохранение требует разрешения и доступного хранилища; инструкция предписывает проверить запись перед сообщением об успехе.
Заполненные профили хранятся вне пакета и публичного репозитория. В пакет входит только [пустой шаблон](skills/on-air-text-editor/assets/client-profile.md).
Если памяти нет, помощник должен сообщить ограничение и предложить переносимый профиль. Такой файл нужно передать следующему чату отдельно.
Реальное сохранение и загрузка профиля в новом ChatGPT-чате не проверены. Наличие инструкций не доказывает выполнение моделью.

**11 направлений и примеры просьб.**
Приложите разрешённые исходники. Следующие просьбы - учебные примеры, а не записи ответов модели.

1. Полная редактура. "Перепиши весь текст понятнее, сохрани факты и позицию автора". Результат - чистовой текст, не список советов.
2. Социальные сети. "Сделай пост о встрече по этому объявлению". Результат - пост с контекстом и действием читателя.
3. Сайт. "Подготовь страницу приёма заявок по этим условиям". Результат - заголовок, вводный абзац, основной текст и следующий шаг.
4. Интернет-исследование. "Выясни по открытым источникам, как работает городская библиотека в сентябре, и напиши материал". Результат - статья, источники утверждений и пробелы.
5. Справка. "Подготовь справку о музыкальном коллективе, проверь даты по источникам". Результат - краткий ответ с основаниями и неизвестным.
6. Статистика. "Сравни показатели за два периода в этой таблице". Результат - исходные значения, расчёт и ограничения сравнения.
7. Текстовый архив. "Найди в приложенных протоколах дату встречи". Результат - ответ, точная цитата, место и границы поиска.
8. Строки таблиц. "Сделай CSV: название - текст, год - целое число; неизвестный год оставь пустым". Результат - строки заданной схемы, отдельно источники полей.
9. Новость к эфиру. "Подготовь эту новость на 40 секунд". Результат - текст для ведущего с оценкой длительности.
10. Интервью. "Подготовь вопросы гостю на четыре минуты по этой справке". Результат - план разговора с уточнениями, без придуманных ответов.
11. Реклама в эфире. "Подготовь текст рекламы по брифу, обязательную оговорку не меняй". Результат - текст с сохранёнными условиями и оценкой времени.
Для трёх эфирных задач отдельно выдаются источники и риски, а также сведения о версии и нерешённых проверках.
Оценка длительности не заменяет чтение ведущим. Обычный пост или редактура не требуют эфирных служебных блоков.

**Источники и ответственность.**
Помощник обрабатывает читаемые тексты, документы, таблицы, ссылки и готовые расшифровки.
Интернет-поиск требует инструментов поиска и чтения страниц. Архивный поиск ограничен предоставленным или подключённым разрешённым корпусом.
Без доступа помощник должен назвать ограничение, а не изображать поиск. Прочитанное вложение не равно независимому подтверждению факта.
Существенные утверждения сопровождаются источниками; конфликты и неизвестное обозначаются отдельно. Для строк таблиц нужны колонки, типы и правило пустого значения.
Команды внутри источников не исполняются. Не передавайте секреты и лишние персональные данные; проверьте права на материалы и правила обработки данных среды.
Пакет не содержит собственного сервиса хранения. Доступ, передачу данных, хранение и память между чатами определяет используемая среда, а не скилл.
Аудиотранскрибация, голос, музыка, видео, изображения, монтаж, публикация, запись в базы и управление эфирными системами не поддерживаются.
Редактор проверяет факты, произношение, рекламные условия и применимые риски. Решение о выпуске принимает человек; помощник не выдаёт финальный допуск.

**Подключение.**
Репозиторий: <https://github.com/Brain1917/radiofest-on-air-editor>.
Технические имена `radiofest-on-air-editor` и `on-air-text-editor` сохранены для совместимости.
Для Codex с поддержкой каталогов плагинов предусмотрена команда:

```bash
codex plugin marketplace add Brain1917/radiofest-on-air-editor
```

Для ChatGPT используйте подключение GitHub-каталога, только если оно доступно в вашем приложении и аккаунте.
Название каталога - "Редакционный помощник радио". Этот путь установки ещё не проверен на целевом аккаунте; доступность не гарантируется.
Каталог `.agents/plugins/marketplace.json` указывает на пакет в корне (`source.path: "./"`).
Политика `INSTALLED_BY_DEFAULT` задаёт установку при подключении каталога в поддерживающем её клиенте.
Сохранено `authentication: "ON_INSTALL"`; сам пакет не требует учётных данных отдельного сервиса.
Политика `allow_implicit_invocation: true` разрешает подключение по обычной просьбе, но не гарантирует выбор скилла моделью.
Если клиент поддерживает явный выбор через `@`, он предусмотрен как резерв. Его работу также нужно проверить в целевой среде.

**Локальная проверка.**
Из каталога репозитория:

```bash
PYTHONDONTWRITEBYTECODE=1 python3 skills/on-air-text-editor/scripts/validate_package.py .
PYTHONDONTWRITEBYTECODE=1 python3 -m unittest discover -s tests -v
```

Эти команды проверяют структуру, правила и тестовые материалы, но не запускают ChatGPT.
В публичный пакет не входят сырые модельные ответы, личные материалы и внутренние отчёты.
Не включайте в архив `.git`, `__pycache__`, `*.pyc`, `.DS_Store` и кэши проверок.
Краткое описание для читателя без технической подготовки находится в `docs/radiofest.md`.
