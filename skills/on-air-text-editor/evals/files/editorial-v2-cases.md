# Учебные источники Radiofest v2

Все лица, события и показатели здесь вымышлены. Материал разрешён для публичных проверок, не для публикации как новости.
Каждый раздел - отдельное виртуальное приложение с указанным именем. Строки считают внутри блока, без заголовка и ограждения.
Передавать модели только разделы из input_refs выбранного случая. Ожидания v2-contracts.json модели не передавать.
Реальная веб-страница описана отдельно в library-web-source.md; этот файл не подтверждает события вне учебного корпуса.
