**Редакционный помощник радио.**
Перед выпуском материала редактор решает, можно ли доверять фактам и понятен ли текст аудитории.
Помощник готовит текст для этого решения. Источники и нерешённые вопросы он показывает отдельно. Выпуск остаётся за редакцией.
Это набор инструкций для искусственного интеллекта, а не замена редактору.

**С какими задачами обратиться.**

- Получить полностью отредактированный текст, сохранив смысл и позицию автора.
- Подготовить пост для подписчиков или материал для сайта по имеющимся сведениям.
- Получить статью по интернет-источникам или краткую справку с основаниями для проверки.
- Сравнить статистику за два периода: увидеть исходные числа, расчёт и ограничения.
- Найти ответ в текстовом архиве вместе с цитатой и точным местом.
- Подготовить строки для таблицы в заданном порядке колонок.
- Получить новость для ведущего, вопросы для интервью или текст рекламы с обязательными условиями.
Для эфира помощник оценивает длительность и отдельно перечисляет сомнения в фактах и произношении. Оценку времени нужно проверить чтением вслух.

**Как начать.**
Подключите помощника в приложении, которое поддерживает установку таких инструкций. Порядок подключения описан в README репозитория:
<https://github.com/Brain1917/radiofest-on-air-editor>.
Приложите материал, который имеете право передавать. Напишите обычную просьбу: "Сделай из этого объявления пост для подписчиков. Сохрани условия участия".
Можно попросить: "Подготовь эту новость на 40 секунд" или "Найди в приложенных протоколах дату встречи".
Если существенных данных не хватает, помощник уточнит один вопрос. Он не должен заполнять пробелы догадками.

**Как учитывать ваши настройки.**
Можно попросить помощника сохранить постоянное правило, например «посты без эмодзи», показать настройки, изменить или удалить их.
В версии 0.3.0 добавлены инструкции профиля клиента. Перед результатом помощник должен прочитать доступный профиль и учесть аудиторию, стиль и формат.
Разовая просьба «в этот раз подробно» не должна менять постоянное правило краткого ответа.
Сохранение зависит от разрешения и возможностей приложения. Если памяти нет, помощник должен сообщить об этом и предложить переносимый профиль.
Профиль нужно передать следующему чату отдельно, если приложение не предоставляет его автоматически. Заполненные профили не входят в публичный пакет.

**Что проверить перед использованием.**
Поиск в интернете возможен только при доступных инструментах поиска и чтения страниц. Для архива нужны доступные записи и разрешение на их обработку.
Без доступа помощник должен сообщить, что поиск не выполнен. Ссылка сама по себе не подтверждает факт.
Проверьте источники, имена, даты, числа и рекламные условия. Не передавайте пароли, закрытые документы без разрешения и лишние персональные данные.
Помощник не работает со звуком, видео или изображениями, не монтирует и не публикует материалы. Он не управляет эфиром и не меняет внешние базы.

**Что уже проверено.**
Версия 0.3.0 - предварительная. Пакет прошёл локальные проверки; новые правила профиля проверены по текстовым сценариям.
Сохранённые примеры предыдущей версии проверялись в Pi. Они не доказывают работу персонализации.
Реальное сохранение и загрузка профиля в новом ChatGPT-чате не проверены.
Установка в реальном ChatGPT и подключение по обычной просьбе пока НЕ проверены. Автоматическое подключение не гарантируется.
Экономия времени не измерена. Окончательную проверку материала и решение о выпуске помощнику не передают.
